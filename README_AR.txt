- اختلاف بيانات الصورة يستدعي فحصًا جديدًا؛ الحكم غير المؤكد لا يُشارك.
- فحص مستقل جارٍ أو قرار موجود لا يستبدله حكم آخر.
- عند انشغال عاملي الفحص، تبقى الصور المنتظرة قابلة للتجميع في دفعات
  تصل إلى 8 صور بدل تحويلها مبكرًا إلى طلبات فردية في طابور التنفيذ.
- توقيع الصورة وربطها بالمنتج وحد المعدل وإعادة المحاولة في الواجهة محفوظة.

ما الذي سيظهر في اللوق؟
PRICE RECOVERY TRACE: لكل عرض دخل استرجاع السعر، مع بصمة العرض واسم
المتجر والسوق والعدادات فقط؛ لا تُسجّل الصورة أو عنوان المنتج أو نص البحث
أو الرابط الكامل أو رد المزود أو المفاتيح.
الأسباب:
  recovered: استُعيد سعر صالح.
  price_absent: عاد نفس المنتج بلا دليل سعر.
  price_rejected: وُجد مبلغ لكن لم يمر بشروط قبول السعر.
  title_conflict: تعارض عنوان المنتج مع العرض الأصلي.
  variant_or_query_mismatch: نفس رقم المنتج بمعلمات مختلفة.
  other_storefront_only: نفس الرقم في متجر إقليمي/مسار سوق آخر فقط.
  listing_not_returned: ردت نتائج لكن الرابط المطلوب لم يطابقها.
  empty_index: الاسترجاع أعاد مجموعة خالية.
  provider_unavailable: تعذر رد المزود ولم تصل نتائج في الدفعة.
batch_records وbatch_failed_lookups يصفان دفعة الاسترجاع؛ بقية العدادات
تخص العرض المحدد. التشخيص لا يسمح بتمرير سعر مرفوض.

WEB IDENTITY REVIEW truncated ... retry=True/False: هل سمح الوقت بالتعافي؟
MEDIA REUSE source=identity_bytes: أعيد استخدام حكم للصورة نفسها.
MEDIA AUDIT batch=...: عدد الصور في الطلب ووقته وعدد الأحكام غير المتاحة.
