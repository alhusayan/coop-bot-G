2) صور المنتجات
- تُفحص الصورة الفعلية بواسطة نموذج الرؤية قبل عرضها داخل البطاقة.
- تستبعد نتيجة «شعار منفصل»، «نص فقط»، «صورة بديلة فارغة» أو «غير واضحة».
- الصورة الحقيقية لمنتج يحمل شعارًا أو كتابة أو ملصقًا أو تغليفًا تظل مقبولة.

- لا تُعرض البطاقة إذا لم تتوفر صورة مقبولة. أخطاء النموذج أو تعذر قراءة الصورة لا تعني الموافقة عليها.

- الصور المتكررة تُفحص مرة واحدة حسب محتواها مع ذاكرة مؤقتة محدودة.
- مسار فحص الصور منفصل عن البحث ولا يخصم رصيد بحث إضافيًا من العميل.
