ما تغير
- ثلاث بطاقات أوضح وأقصر على الجوال، وثلاثة أعمدة على الكمبيوتر.
- الأسعار نفسها: 20 بحث / $4.99، 50 / $9.99، 100 / $17.99.
- إبراز باقة 50: نرشحها لك. باقة 100: أفضل قيمة.
- سعر تقريبي لكل بحث، وتوفير تقريبي 20% و28% مقارنة بوحدة البحث في باقة 20.
- توضيح دفعة واحدة، بدون اشتراك، بدون انتهاء، ونفس المزايا لكل الباقات.
- النصوص الجديدة مترجمة إلى لغات الواجهة الست عشرة.
- مسح رسالة نجاح الدفع عند الخروج أو الانتقال لصفحة أخرى؛ منع ظهور تأكيد قديم حتى إن وصل الرد بعد مغادرة صفحة التأكيد.
- نافذة تجهيز واضحة فور الضغط؛ تتغير حالة زر الباقة المختارة فقط.
- تحميل Paddle مسبقًا عند فتح الباقات، وتجهيز المعاملة والمكتبة بالتوازي بعد الضغط.
- مسار Paddle لا ينتظر إعدادات MyFatoorah غير المستخدم. استعادة المشتريات تستمر في فحص المزودين عند طلبها.
- إخفاء Pay another way بواسطة إعداد Paddle الرسمي showNonExpressPaymentMethods=false.
- زر Card ظاهر مباشرة خارج إطار Paddle، يفتح الدفع بالبطاقة للمعاملة نفسها ولا ينشئ طلبًا جديدًا.
- الإلغاء أثناء التجهيز لا يفتح نافذة متأخرة. حماية الخادم من تكرار المعاملة باقية.

اللون الأخضر — خطوة لازمة داخل حساب Paddle
أخضر Findzia الحالي في الوضع النهاري: #354E3F.
واجهة الباقات، زر Card وإطار الدفع تتبع ثيم Findzia، ويُمرر الوضع الليلي إلى Paddle.
زر Pay الفسفوري داخل إطار Paddle لا يمكن تغيير لونه بـ CSS الموقع أو بمعامل color غير موثق.
من حساب Paddle افتح Checkout Settings / Checkout configuration ثم خيارات تخصيص المظهر.
اضبط لون الزر/العلامة التجارية إلى #354E3F، والنص إلى #FFFFFF حيث تتوفر هذه الخيارات.
راجع تبويبي Inline وOverlay إذا ظهرا في حسابك؛ زر Card يستخدم Overlay.
هذه الحزمة لا تعدّل إعداد اللون الداخلي في حساب Paddle تلقائيًا.
مرجع Paddle الرسمي:
https://www.paddle.com/help/start/set-up-paddle/can-i-customize-my-checkout-look-and-feel

التحقق
نجح البناء والتحقق من صياغة JavaScript.
الاختبار يحاكي مزودي الدفع بالكامل؛ لا توجد عمليات دفع حقيقية في الاختبار.
راجع verification/TEST_RESULTS.txt للنتيجة التفصيلية.
اختُبر الجوال 320 و390 والكمبيوتر 1280، العربية والإنجليزية والوضعان النهاري والليلي، وملاءمة عدة لغات إضافية للشاشات الصغيرة.
اختُبرت استجابة الضغط، عدم إنشاء معاملات بمجرد فتح الباقات، عدم تكرار الطلب مع الضغط المتكرر، إلغاء التجهيز قبل وصول الخادم، أخطاء الشبكة، حالات الانتظار، Card للمعاملة نفسها، وتأكيد الدفع بعد الخروج.
لقطات المعاينة تعرض بيانات اختبار، ومنها سطر Test mode. الموقع الفعلي يستخدم إعداد Paddle الحالي دون تغييره.
زمن التجهيز الحقيقي يتأثر بالشبكة وPaddle. الفتح الفوري هنا يخص واجهة التجهيز، وليس وعدًا باكتمال اتصال الدفع فورًا.
لم يُختبر Apple Pay الحي أو تُسحب مبالغ فعلية.

حدود التغيير
لا تعديل على البحث أو الفلاتر أو ملفات Python أو الأسعار أو المفاتيح أو قاعدة البيانات.
لم يتم إنشاء منتجات أو معاملات أو اشتراكات في حساب Paddle الحي.
البحث ما زال يستخدم المسارات الحالية، والتغيير محصور في الباقات والدفع ونصوصها.
