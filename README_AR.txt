Findzia 156.7.86 — تدفق الصور والبطاقات

main.py
findzia_product_media.py
frontend/source/findzia-home.liquid

التركيب:
ارفع الملفات الخمسة في تحديث واحد إلى GitHub بنفس المسارات.
إذا كنت ترفع الخلفية والواجهة على مرحلتين، ارفع main.py وfindzia_product_media.py أولًا، ثم ملفات frontend الثلاثة معًا.
Railway يبني الواجهة من ملفات المصدر؛ لا ترفع مجلد public من إصدار سابق.
لا تحتاج تغيير أي variable.
هذا الملف جاهز للرفع؛ لم يُنشر تلقائيًا على Railway.

ما تغيّر:
- دفعات التدقيق الأولى صغيرة (عادة 1، ثم 2، ثم 3 منتجات)، مع استمرار أولوية العروض ذات الصور والأسعار الجاهزة والمحلي. البقية تتابع بأحجام الدفعات المعتادة وبنفس حد التوازي.
- عند وجود حكم صريح بأن الصورة تعرض منتجًا، تُحفظ نسخة JPEG المصغّرة نفسها التي فحصها النموذج مؤقتًا، وتُرسل برابط عشوائي يعرض هذه البايتات فقط. المتصفح يعرضها بعد اكتمال تحميلها وفك ترميزها، بدون انتظار فحص صور إضافي.
- هذه النسخة هي صورة المعاينة المدققة (384 بكسل افتراضيًا وفق إعداد السيرفر الحالي)، وليست تنزيلًا جديدًا للصورة الأصلية عالية الدقة.
- انتهاء صلاحية الرابط أو فقده بعد إعادة تشغيل السيرفر يعيد التحميل عبر صورة المتجر والفحص المعتاد. الروابط لا تشغّل تنزيلات أو طلبات ذكاء اصطناعي، والذاكرة محدودة بـ16 MiB و256 صورة لمدة أقصاها 15 دقيقة.
- تصحيح قبول مقاييس إصدارات الواجهة الحديثة، وإضافة قياس أول ست بطاقات محملة دون تسجيل الصورة أو كلمات بحث المستخدم.

السلوك المحفوظ:
تدقيق تطابق المنتج، إخفاء الصور المرفوضة والنتائج غير المعتمدة، شروط الأسعار، واستثناء SHEIN بدون سعر. إعدادات الدفع وباقي التصميم كما في النسخة المنشورة.
لا تغيير على استعلامات مصادر البحث أو مدة كاش نتائج البحث. دفعات التدقيق الأولى الأصغر قد تزيد عدد طلبات التدقيق قليلًا حسب وصول الصور.

التحقق:
89 اختبار Python، و40 فحص متصفح لمسارات التدفق والصور المنتهية والروابط غير المعتمدة، و54 فحص لقواعد SHEIN و42 فحص متصفح لاستمرارية عرضه.
بناء الواجهة وفحص Python ناجحان. خدمات البحث والدفع الخارجية محاكاة داخل الاختبارات؛ الأرقام ليست قياسًا لسرعة البحث الحي.
