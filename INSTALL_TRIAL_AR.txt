- سجل حي من 7 أسطر مع تلاشي، يعتمد على مراحل البحث والعروض المستلمة فعلاً.

- هيدر مضغوط وقت النتائج وصورة تستفيد من المساحة المتاحة بعد حساب ارتفاع بقية العناصر.
- معالجة JSON غير الصالح وإعادة محاولة محدودة تلقائيًا؛ لا يُستبدل قرار الذكاء بفرز سعر آلي.

- 19 اختبار Python و17 اختبار Node نجحت.
- بناء الواجهة ومدخلات Docker وفصل صفحة التجارب عن الرئيسية نجحت.
